# ADR-003: AGPL-3.0-or-later for our core

**Status:** Accepted in principle — 2026-08-20

## Decision
Roundtrip-owned source will use `AGPL-3.0-or-later`, subject to a final licensing review before public release.

## Intent
Commercial use and hosted services are allowed, while modifications to the covered networked software remain subject to AGPL source-availability obligations. Third-party code retains its own license and must remain clearly separated.
